## Review

- 매매는 공식 공개 시작 시점인 2006년부터 선택할 수 있습니다.
- 전월세는 공식 공개 시작 시점인 2011년부터 선택할 수 있습니다.
- 연도 선택지는 현재 연도까지 동적으로 생성되며, 거래 유형 전환 시 지원 범위로 자동 보정됩니다.
- 검증: `npm run lint`, `npm test` (19개 통과), `npm run build` 통과.
